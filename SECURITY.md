# Security Policy

EventRisk Kempen bevat mogelijk veiligheidsgevoelige evenementgegevens. Meld beveiligingsproblemen niet via een openbaar GitHub Issue.

## Een probleem melden

Gebruik het interne beveiligings- of incidentkanaal van de beherende organisatie. Vermeld:

- getroffen versie/commit;
- duidelijke reproductiestappen;
- verwachte en werkelijke uitkomst;
- mogelijke impact;
- uitsluitend noodzakelijke, geanonimiseerde bewijsinformatie.

Plaats nooit tokens, API-keys, client secrets, persoonsgegevens of echte dossierinhoud in een melding.

## Ondersteunde versies

Alleen de meest recente formeel goedgekeurde productie- en acceptatierelease wordt ondersteund. Beveiligingsupdates krijgen prioriteit volgens het interne incident- en wijzigingsbeleid.

## Geheimen

Vermoedt u dat een secret gelekt is, trek het secret onmiddellijk in, roteer het en start de interne incidentprocedure. Alleen het verwijderen uit GitHub is onvoldoende wanneer een geheim in de Git-geschiedenis heeft gestaan.
